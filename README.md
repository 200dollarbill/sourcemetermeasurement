# TMR Sensor Magnetic Field Response Measurement

This repository contains two MATLAB App Designer programs used to measure how the resistance of a TMR sensor changes under a simulated magnetic field. Both programs talk to lab instruments over GPIB, drive a Helmholtz coil with a controlled current, and log the resulting resistance response of the device under test (DUT).

This document explains the physical setup, the measurement procedure, and how to operate each program.

## Background

The DUT is a TMR sensor that changes resistance in response to an applied magnetic field. To characterize this response, we place the DUT inside a Helmholtz coil and drive the coil with a controlled DC current from a Kepco 36 12M power supply. The coil converts that current into a magnetic field at the DUT. A source meter is connected across the sensor pins to actively measure its resistance while the field changes, and a Lakeshore gaussmeter can be used to measure the actual field being generated near the DUT.

The DUT board carries an array of TMR sensor blocks (block 1 has pins A+ and A-, block 2 has pins B+ and B-, and so on). Only one block can be measured at a time, since the source meter can only connect to one pair of pins at once.

Sweeping the coil current and recording resistance at each step lets you plot resistance against input current, and, once the current is converted to an actual magnetic field, resistance against field strength.

- Kepco 36 12M power supply, driving current into the Helmholtz coil
- Helmholtz coil, generating the magnetic field around the DUT
- DUT board with TMR sensor blocks
- Source meter, connected to one sensor block at a time, measuring resistance

All instruments communicate over GPIB. The GPIB addresses are fixed values already configured on each instrument, and you enter them in the connection panel of whichever program you are using.

## Which program to use

There are two programs, and they are built for different situations.

**LibraryBasedGUIMeasurement** is used when you already have a lookup table (LUT) relating coil current to magnetic field, or when you are working with small fields (for example, a field generated by a single wire) where using the Helmholtz coil and gaussmeter setup is not practical. It does not need the gaussmeter at all, since the field value at each point is interpolated from the LUT based on the measured output current. Because of this, you do not need to place a gaussmeter probe near the DUT, so step 5 of the procedure below can be skipped. You also cannot set arbitrary sweep parameters beyond step time and measurement count, since the sweep points come from the LUT itself.

**ControllerGUI** is used when you want the actual generated field measured directly with the gaussmeter rather than estimated from a table. It requires the gaussmeter probe to be positioned close to the DUT (step 5 of the procedure), but does not use a LUT, since it reads the real field instead of interpolating it. Because the gaussmeter is sensitive to induction from the measurement current running through the board, the probe must be placed close to the sensor without touching the pins. This program is general purpose and can be used with DUTs other than the TMR sensor as well.

## General measurement procedure

Follow these steps regardless of which program you are using. Steps that only apply to one program are marked accordingly.

1. Turn on the measurement instruments (power supply, source meter, and gaussmeter if needed).
2. Turn on the power supply.
3. Place the board inside the Helmholtz coil.
4. Connect the sensor pins on the board to the source meter. Only connect the two pins (positive and negative) belonging to the sensor block you intend to measure.
5. Place the gaussmeter probe as close to the sensor as possible without touching the sensor pins. Only needed for ControllerGUI.
6. Start the program and connect to the devices using their GPIB addresses, which are already set on the instruments themselves and just need to be entered into the program.
7. Enter the measurement parameters for your sweep.
8. Select the preset LUT file used to interpolate the magnetic field from the input current. Only needed for LibraryBasedGUIMeasurement.
9. Start the measurement.

## LibraryBasedGUIMeasurement

### Overview

This program sweeps the coil current between a start and end value, measures resistance at each step, and interpolates the corresponding magnetic field from a preloaded lookup table rather than measuring it directly.

### Connecting

In the Connection panel, enter the GPIB address for the power supply (Supply Addr) and the source meter (Source Meter addr), then press Connect. The mode dropdown only offers one option here, Supply plus Source meter, since the gaussmeter is not used in this program. The status label will show Online once both instruments respond. Press Disconnect when you are done, which also safely powers down the outputs.

### Loading the LUT

In the LUT panel, press Choose LUT and select an Excel or CSV file where the first column is current and the second column is the corresponding magnetic field. Once loaded, the panel displays the filename, number of data points, the step size inferred from the spacing between the first two current values in the table, and the maximum and minimum current covered by the table. A measurement cannot be started until a LUT is loaded.

Note that in this program the step size of the sweep is not set manually. It is taken directly from the spacing of the LUT you load, since each sweep point needs to correspond to a value the LUT can interpolate a field for.

### Setting parameters

In the Settings panel you can enter:

- Start Current (A), the current the sweep begins at
- End Current (A), the current the sweep ends at
- Step time (s), how long the program waits after each current change before measuring, and again after measuring before moving to the next step
- Filename, used as the base name when saving data or figures
- Hysteresis, if checked, the sweep will run from start to end and then back from end to start
- Mode, choose between Staircase (the sweep runs straight from start to end) or Return to Zero, where the current is returned to zero between every step rather than moving directly to the next value

Start and end current values entered outside the range covered by the LUT will automatically be clamped to the LUT boundaries.

### Running a measurement

Press Start to begin the sweep. At each step the program sets the coil current, waits the step time, reads the resistance from the source meter, reads back the actual current from the power supply, and interpolates the field from the LUT using that measured current. You can check Real Time Plot to watch the resistance versus current and resistance versus field plots update live in the two tabs, or leave it unchecked and press Plot afterward to render the full sweep at once. Press Stop at any time to end the sweep early. Once finished the program computes and displays the MR ratio based on the resistance range recorded.

### Saving results

Save Excel writes the recorded current, resistance, interpolated field, MR ratio percent, and sensitivity to a spreadsheet next to the filename you specify. Save Fig exports the two plots as a PNG or MATLAB fig file.

## ControllerGUI

### Overview

This program sweeps the coil current between a start and end value while directly measuring both the resistance of the DUT and the actual magnetic field with the gaussmeter, rather than relying on an interpolated table. It also supports repeating the sweep over multiple cycles and logs data against time in addition to against current.

### Connecting

In the Connection panel, enter the GPIB address for the power supply (Supply Addr), the source meter (Source Meter addr), and the gaussmeter (Gaussmeter Addr) as needed for your mode. The dropdown lets you choose which instruments to connect to: Supply plus Source meter, Supply plus Gaussmeter, or All instruments. Press Connect, and the status label will show Online once the selected instruments respond. Press Disconnect when finished.

### Setting parameters

In the Settings panel you can enter:

- Max Current (+) and Min Current (-), the absolute current limits the sweep is not allowed to exceed
- Start Current (A) and End Current (A), the current values the sweep runs between, clamped to the max and min limits above
- Step size (A), how much the current changes at each step
- Step time (s), the total time budget for each step, covering settling and measurement
- Measure time (s), the point within each step where the sensor is read, must be less than or equal to step time
- Filename, used as the base name when saving data or figures

In the Control panel you can also set:

- Cycle count, how many times the full sweep repeats
- Delay per cycle (s), how long the program waits between repeated cycles
- Hysteresis, if checked, each cycle sweeps from start to end and back
- Mode, choose between Normal, where the current moves directly between steps, or Return to Zero, where the current returns to zero after every step before moving on

### Running a measurement

Press Start to begin. At each step the program updates the coil current, then takes readings of current and field at the start, middle, and end of the step window (this is what feeds the time based plots), reads resistance from the source meter partway through the step, and reads the field from the gaussmeter. A Time to finish estimate is shown based on your step time, measure time, cycle count, and delay settings. Check Real Time Plot to watch the plots update live, or press Plot afterward if you left it unchecked. Press Stop at any time to end the run early.

### Plots

Five tabs are available covering the sweep:

- Ohms/A, resistance against input current
- Ohms/G, resistance against measured magnetic field
- G/A, measured magnetic field against input current
- A/s, measured current against time
- G/s, measured magnetic field against time

If you are in Supply plus Gaussmeter mode without a source meter connected, the first two tabs show field against current instead of resistance, since no resistance data is being collected.

### Saving results

Save Excel writes the recorded current, resistance, field, MR ratio percent, and sensitivity to a spreadsheet. Save Plot exports all five plots as a PNG or MATLAB fig file.

## Parameter reference

A quick summary of what each setting controls, since the two programs use them slightly differently.

**Step size (A)**
How much the coil current changes at each step of the sweep. In ControllerGUI this is set directly. In LibraryBasedGUIMeasurement it is not set directly, it is taken from the spacing between values in the loaded LUT.

**Step time (s)**
How long the program pauses after changing the current before it takes a measurement, and how long it pauses again after measuring before moving to the next step. In ControllerGUI this also defines the total window within which the measure time occurs.

**Measure time (s)**
ControllerGUI only. Marks the point within a step where the resistance reading is taken, allowing the current to settle before the measurement happens partway through the step window.

**Filename**
The base name used when saving data to Excel or exporting figures.

**Start Current (A)**
The current the sweep begins at. Must fall within the current limits (LUT bounds for LibraryBasedGUIMeasurement, or Min and Max Current for ControllerGUI), otherwise it is automatically clamped to the nearest valid limit.

**End Current (A)**
The current the sweep ends at. Also automatically clamped to the current limits if entered outside range.

**Max Current and Min Current**
ControllerGUI only. The absolute current bounds the sweep cannot exceed, regardless of what start and end current are set to. In LibraryBasedGUIMeasurement these bounds come from the maximum and minimum current values present in the loaded LUT.

**Hysteresis**
Available in both programs. When checked, the sweep runs from start to end and then back from end to start, letting you see if the resistance response differs depending on sweep direction.

**Mode (Staircase or Return to Zero in LibraryBasedGUIMeasurement, Normal or Return to Zero in ControllerGUI)**
Return to Zero drives the coil current back to zero between every step rather than moving straight to the next target current, which is useful for checking whether the sensor response depends on the current path taken to reach a given field, not just the field itself.

**Cycle count and Delay per cycle (s)**
ControllerGUI only. Cycle count repeats the entire sweep that many times, and Delay per cycle sets how long the program pauses between each repeated sweep.

## Output data

Both programs can export an Excel file containing the current recorded from the power supply, the resistance recorded from the source meter, the field (interpolated or measured), the MR ratio in percent, calculated as the change in resistance relative to the minimum resistance recorded, and an overall sensitivity value in ohms per gauss based on the total resistance change across the total field change in the sweep. Both programs can also export the plots as PNG images or MATLAB fig files for later use.
